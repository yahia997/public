A commit that only exists on your local machine isn't shared with anyone. Pushing sends your commits to a remote repository (e.g., on GitHub).

**What to do:**

1. Create a repository on GitHub (if you don't have one yet).
2. Connect your local repo to it: `git remote add origin <your-repo-url>` (Skip if already connected).
3. Push your commit(s) from Phase 2: `git push -u origin <branch>`.
4. Submit your repository link through the platform (CLI tool) to trigger evaluation.
