### What is git?

Git is a distributed version control system (VCS) that tracks changes in files, especially source code.

Git lets you save versions of your project, see what changed, undo mistakes, and collaborate with other developers.

### What is a Git repository?

A Git repository (repo) is a directory that Git uses to track the history of a project.

Git creates a hidden directory (you do not need to understand it):

**Types of git repos:**

- **Local:** Changes are stored locally on your device.
- **Remote:** Your code is managed on a platform remotely, such as GitHub or GitLab.

**2 ways to initiate a git repo:**

- **git init:** To create a local git repository (Makes the current directory a git repo).
- **git clone <repo-url>:** Copy a remote repository to your device locally.

Now you will create your first GitHub repo:

1. Create a new folder for your project (or use an existing one).
2. Open a terminal inside it.
3. Run `git init` to initialize a Git repository.
